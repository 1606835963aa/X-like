# 开发与构建

项目使用 Node.js 24、npm 和 Git。桌面、手机和资料库服务共用 `src/ui` 前端。电脑版默认启动本机资料库，远程服务连接为可选项。

## 目录

| 目录 | 内容 |
|---|---|
| `src/ui` | React 界面与主题样式 |
| `src/desktop` | Electron 桌面、X 登录与增量同步 |
| `src/server` | HTTP 服务、SQLite 资料库与导入导出 |
| `src/shared` | 资料类型、X 响应解析、标签与目录匹配 |
| `android` / `ios` | Capacitor 原生工程 |
| `public/icon.svg` | Logo 的图形源文件 |
| `design` | 界面规范、主题变量与品牌说明 |
| `docs/assets` | README 的演示截图与封面 |
| `resources` | 桌面 PNG、ICNS 与 ICO 图标 |
| `private` | 本机签名、部署说明与资料备份，Git 忽略 |
| `release` / `tmp` | 安装包与临时文件，Git 忽略 |

## 运行

```sh
npm ci --cache ./tmp/npm-cache
npm run build
npm start
```

`npm run dev` 启动网页界面开发服务。桌面应用的入口是 `dist/desktop/main.cjs`；运行前需要完成构建。

Electron 下载需要重试时，可以使用项目内缓存：

```sh
electron_config_cache="$PWD/tmp/electron-cache" node node_modules/electron/install.js
```

## 测试

```sh
npm test
npm run test:collector
npm run build
```

检查范围见 [验证与平台状态](验收记录.md)。

自动测试覆盖资料合并、搜索、导入导出、作者与标签、媒体保存策略和同步保护。Electron 采集场景使用模拟 X 响应与独立本机资料库。

## 图标

编辑 `public/icon.svg` 后运行：

```sh
node scripts/icons.mjs
```

图标脚本生成 Mac ICNS、Windows ICO、桌面 PNG、Android 启动与自适应图标，以及 iOS App Icon。应用侧栏、欢迎页和网页图标直接使用同一份 SVG。

README 的封面可在更新 `docs/assets/library-desktop.png` 后运行 `node scripts/readme-cover.mjs` 生成。

## 桌面安装包

```sh
npm run package:mac
npm run package:win
```

Mac 输出 `release/mac-arm64/拾藏.app`；Windows 输出 `release/Shizang-0.1.0-Windows-x64.exe`。Mac 应用可打包为 ZIP 分发。

## Android

需要 JDK 21、Android SDK 36 与 Build Tools 35。配置 `JAVA_HOME` 和 `ANDROID_HOME` 后运行：

```sh
npm run build
npx --cache ./tmp/npm-cache cap sync android
node scripts/android-build.mjs
```

输出为 `release/Shizang-0.1.0-Android.apk`。签名保存在 `private/android-release.keystore` 与 `private/android-signing.json`，后续更新需要保留同一签名。

## iOS

原生工程位于 `ios/App`。需要 macOS、完整版 Xcode 和对应的签名配置；当前尚未生成 iPhone 安装包。

## NAS 服务与离线包

```sh
npm run build
npm run server
```

服务环境变量：

| 变量 | 用途 |
|---|---|
| `SHIZANG_DATA_DIR` | 持久资料目录 |
| `SHIZANG_NAME` | 资料库显示名称 |
| `HOST` | 监听地址 |
| `PORT` | 服务端口 |

Docker 的构建与部署见 [NAS 部署](NAS部署.md)。生成 ARM64 离线包需要 `crane`、`tar` 和 `zip`：

```sh
node scripts/package-nas.mjs
```

`CRANE_BIN` 可以指定 `crane` 可执行文件。输出为 `release/Shizang-0.1.0-NAS-arm64.zip`。
