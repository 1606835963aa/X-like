# 安装、更新与备份

桌面安装包内置运行环境，默认使用本机资料库。单机使用无需安装 Node.js、Docker 或配置 NAS。

## 安装

从 [版本发布页](https://github.com/1606835963aa/X-like/releases) 下载与电脑匹配的包：

| 电脑 | 文件 | 操作 |
|---|---|---|
| Apple Silicon Mac，macOS 13+ | `Shizang-<版本>-macOS-arm64.zip` | 解压，将「拾藏.app」拖入「应用程序」，再打开 |
| Windows x64 | `Shizang-<版本>-Windows-x64.exe` | 运行安装向导，选择目录后完成安装 |

Mac 使用临时签名，Windows 暂无发布者数字签名。首次打开时：

- Mac 如提示无法验证开发者，确认下载来源后，在“系统设置 → 隐私与安全性”中选择“仍要打开”。见 [Apple 操作说明](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)。
- Windows 如显示 SmartScreen 提示，确认下载来源后选择“更多信息 → 仍要运行”。受管理电脑可能由组织策略限制，见 [Microsoft 说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)。

发布页的 `SHA256SUMS-<版本>.txt` 用于核对文件。Mac 可使用 `shasum -a 256 <文件>`；Windows PowerShell 可使用 `Get-FileHash <文件> -Algorithm SHA256`。

## 首次使用

1. 打开拾藏，默认进入这台电脑的本机资料库。
2. 在软件打开的 X 官方页面登录账号。
3. 手动同步新增收藏、点赞或两者。
4. 使用搜索、作者目录、标签目录和整理功能查看资料。

多台电脑共用资料时，按 [共享资料库](共享资料库.md) 配置。X 登录会话保留在登录设备。

## 更新

1. 在设置中导出 JSON；如需连同已保存的视频一起备份，按下一节复制完整本机资料库。
2. 完成或停止同步、视频保存任务，退出拾藏。Mac 使用“拾藏 → 退出拾藏”完成退出。
3. Mac 解压新版后替换“应用程序”里的「拾藏.app」；Windows 在同一系统用户下运行新版安装包覆盖安装。
4. 打开新版本，在设置中确认版本和当前资料库，检查原有资料是否可见。

资料保存在系统应用数据目录，替换程序不需要删除该目录。当前版本采用手动下载更新。

## 本机备份与迁移

菜单“资料库 → 打开本机资料目录”打开 `library` 文件夹。完整备份时退出拾藏，再复制整个文件夹；其中包含数据库、整理信息和手动保存的视频。

系统应用数据目录通常为：

- Mac：`~/Library/Application Support/拾藏`
- Windows：`%APPDATA%\拾藏`

跨电脑或切换资料库迁移正文、标签和备注时，在原资料库导出 JSON，再到目标资料库导入。完整视频备份使用 `library` 文件夹。

远程连接凭证受当前系统用户的加密保护，X 会话也属于登录设备。另一台电脑单独连接远程资料库和登录 X。

## 启动故障与恢复

启动故障窗口可打开日志、资料目录、重试或选择备份。正常运行时可通过“资料库 → 查看升级前备份”找到备份，通过“重启并恢复本机资料库”恢复。

数据库结构升级前会自动生成经校验的备份；应用版本变化本身不一定改变数据库结构。恢复前的数据库会另外保留，已有媒体文件不改动。

需要反馈问题时，按 [反馈与诊断](反馈与诊断.md) 整理版本、复现步骤和相关错误片段。
