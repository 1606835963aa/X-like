# 反馈与诊断

## 选择入口

- [功能错误](https://github.com/1606835963aa/X-like/issues/new?template=bug_report.yml)：启动、导入、搜索、同步、播放、连接与恢复问题。
- [功能建议](https://github.com/1606835963aa/X-like/issues/new?template=feature_request.yml)：描述希望改进的操作和场景。
- [安全反馈](../SECURITY.md)：凭证泄漏、越权读取、任意文件访问等问题走私密渠道。

反馈表单随仓库文档提供。私人仓库的表单需要仓库访问权限；公开仓库的安全私报入口需要维护者单独开启，安全政策提供入口不可用时的联系方法。

## 复现信息

1. 在设置中查看拾藏版本，记录电脑系统版本。
2. 说明使用本机还是远程资料库。远程模式只需说明“局域网”或“跨网络”，地址用占位值替代。
3. 写出从哪一页开始、执行的操作、出现的结果和预期结果。
4. 使用演示数据复现。截图只保留相关区域，遮住账号、作者、私人收藏和地址。

同步问题还需说明收藏、点赞或两者，以及是否出现限流、登录验证或超时提示。显示与输入问题补充系统缩放比例和输入法。

## 日志位置

菜单“资料库 → 打开启动日志目录”打开 `logs` 目录：

- `startup.log`：启动、数据库、权限与退出故障。
- `startup.previous.log`：轮转后的启动日志。

菜单“资料库 → 打开本机资料目录”打开 `library` 文件夹；返回上一级可找到：

- `connection.log`：X 页面、同步连接阶段、HTTP 状态与错误码。
- `connection.previous.log`：轮转后的连接日志。

软件启动时初始化连接诊断，首次写入时处理已有日志中的地址和凭证，并限制日志大小；日志保留连接方式、操作阶段和错误码。

只复制与问题对应的几行并检查内容。Cookie、连接码、设备凭证、X 会话目录、完整数据库和私人收藏不作为问题附件。安全问题通过私密渠道使用占位值说明。

## 本机与远程故障

- 本机启动失败：保留当前资料目录，从启动窗口查看日志或选择备份恢复。
- 远程连接失败：在设置中切回本机确认本机资料可见，再检查远程服务是否运行、网络是否互通。
- X 验证或限流：在 X 官方页面处理提示，等待允许的重试时间后手动同步。

安装、更新和完整备份方法见 [安装与更新](安装与更新.md)。
