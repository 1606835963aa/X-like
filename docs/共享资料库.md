# 共享资料库

共享资料库可以运行在普通电脑、云服务器、家庭服务器或 NAS 上。只在一台电脑使用拾藏时，直接使用默认的本机资料库即可，无需启动这项服务。

## 在普通电脑上运行

需要 Node.js 24。在项目目录完成构建并启动服务：

```sh
npm ci --cache ./tmp/npm-cache
npm run build
npm run server
```

默认端口为 `5368`，启动时终端会显示连接码。

- 同一台电脑上的拾藏：在设置中连接 `http://127.0.0.1:5368`。
- 手机或另一台电脑：填写服务电脑的局域网地址，例如 `http://192.168.1.100:5368`。
- 两台设备填写同一个连接码；已连接的电脑也可以在设置中显示连接码。

运行服务的电脑需要保持开机。设备要处于可互通的网络中，服务电脑需要允许设备访问 `5368` 端口。跨网络使用时，可通过已经接入的私网连接服务。

## 本机资料与共享资料

桌面默认的本机资料保存在系统“拾藏”应用数据目录中。独立服务的资料默认保存在项目 `data` 目录，两者是不同的资料库。

电脑版连接远程资料库后，可在“设置 → 资料库”直接切换本机和远程。地址与连接凭证加密保留，切换及重启不需要重新输入连接信息。需要使用其他远程地址时，选择“更换远程资料库”。

切换不会自动搬移资料或启动 X 同步。远程服务暂时离线时，可以切回本机继续使用；本机模式启动不连接远程服务。

将本机已有内容放入共享资料库时：

1. 在本机资料库的设置中导出 JSON。
2. 切换到共享资料库。
3. 导入刚才导出的备份。

电脑和手机之后都连接这一份共享资料库，由电脑同步 X 的新增内容。切换资料库不会自动搬移已有资料。

## 配置

| 环境变量 | 默认值 | 用途 |
|---|---|---|
| `SHIZANG_DATA_DIR` | `data` | 持久资料目录 |
| `SHIZANG_NAME` | `拾藏 · 共享资料库` | 设备上显示的名称 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `PORT` | `5368` | 服务端口 |

Docker 和 NAS 的部署方法见 [NAS 部署](NAS部署.md)。

## 备份

停止服务后复制完整 `data` 目录，再重新启动服务。该目录保存正文、整理信息、媒体文件与设备连接配置。JSON 导出适合迁移正文与整理信息；手动保存的视频通过完整目录备份保留。
