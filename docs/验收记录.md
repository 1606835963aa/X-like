## 资料、恢复与媒体

电脑版默认使用本机资料库，无需 NAS。自动检查覆盖远程凭证加密、本机与远程切换、选择的重启恢复及远程离线后切回本机。

数据库结构升级前生成经校验的备份；备份失败时不升级，迁移失败时回滚。旧软件拒绝更高结构版本。恢复保留原数据库及 WAL，媒体目录不变；旧备份缺少本机凭证时会重建有效凭证。

浏览和同步不自动保存图片、头像或视频，未保存媒体不触发共享服务访问 X。手动保存选定视频后写入当前资料库，已保存视频支持分段读取。JSON 用于迁移正文与整理信息，完整资料目录备份包含媒体。

启动日志隐藏地址、个人路径与凭证。连接日志保留阶段、模式、状态和错误码，隐藏地址与凭证，并在首次写入时处理已有连接日志。单份连接日志约 1 MiB 后轮转。

## 登录与反馈

X 账号在官方页面登录，软件不读取其他浏览器的 Cookie。Google 内嵌登录提供返回 X 登录的提示；Apple 官方页面可通过受控弹窗打开，完整账号授权流程按实际账号验收。

“帮助”菜单、双语 README 和问题表单提供文档、功能错误、建议与安全反馈入口。GitHub 私密漏洞报告需要在公开仓库开启；入口不可用时，安全政策提供不含漏洞细节的联系请求表单。表单及文档随源码交付，GitHub 页面以已推送内容为准。

## 交付

Mac ZIP 的中文文件名、执行权限、14 个符号链接和全部文件内容与通过签名校验的应用一致。Windows 安装器与内部压缩包完整性通过检查，嵌入程序及 ASAR 与当前构建一致。桌面包含项目 AGPLv3、依赖许可及 Chromium 许可。

公开源码包包含网页入口、构建配置、锁文件、源代码、双语 README、安全政策、贡献指南、问题表单及用户文档。包中不含 Git 历史、个人配置、数据库、node_modules 或安装包。无历史源码目录可独立检查，并且不会使用上级仓库的历史。交付方法见 [公开源码交付](公开源码.md)。

个人开发仓库和既有提交保留为私人资料，公开交付使用干净源码。安装包、源码包和本机核验报告位于 Git 忽略的 `release`。验收使用独立资料，不对线上资料库进行故障测试。
