## 功能检查

25 项自动测试与 6 项 Electron 采集场景检查通过，覆盖：

- 重复推文合并、收藏与点赞分别保存、再次同步保留整理信息。
- 中断同步保留已有资料，完整同步只更新对应账号与来源。
- 中文搜索、组合关键词、来源、媒体、日期与标签筛选。
- 归档恢复、JSON 备份恢复及双来源保留。
- X 长正文和引用解析，忽略广告。
- X `like.js`、JSON 与包含换行和逗号的 CSV 导入。
- 中文 CSV 重新导入及表格公式开头文字的保留。
- 两个设备访问同一服务，撤销设备后凭证失效，未授权请求拒绝访问。
- 服务重新启动后保留资料，并识别中断任务。
- 已保存预览图读取、原图预览回退、原视频分段读取。
- 新装与旧设置迁入后自动同步关闭；用户主动开启后的选择可保留。
- 增量读取只写入对应账号、来源的新内容，遇到整页已收录内容或重复翻页位置停止。
- HTTP 401、403、429 与响应正文中的限流、失效登录、账号锁定和验证提示停止整个同步；不重试、不继续另一种来源，已收录资料保留。
- 限流暂停时间在采集器重新创建后仍生效；支持等待秒数、日期和限流重置时间，不截短较长的等待要求。
- 等待下一页时可手动停止，历史读取请求在访问 X 前被拒绝。

采集场景检查使用模拟 X 响应与独立本机测试资料库。正式 Mac 应用已确认自动同步开关为关闭状态，同步弹窗仅提供新增收藏与点赞，启动和界面核验未触发 X 采集。

TypeScript 类型检查与生产构建通过。

## 界面检查

共用前端在桌面和 375 像素手机宽度下检查了搜索、组合筛选、详情、标签、文件夹、备注、卡片与列表切换、浅色与深色、弹窗焦点和键盘操作。手机筛选面板没有横向溢出，日期控件可并排显示。9 组定义的文字颜色与背景对比检查通过。

手机布局使用底部导航和抽屉面板，桌面布局使用侧栏。界面截图位于 `release/screenshots`，使用独立资料副本展示。

Electron 原生窗口使用当前生产构建和两条真实媒体资料检查：详情关闭按钮可关闭面板；未保存的 60 秒 H.264/AAC 视频通过当前设备播放，已保存的 3 秒 H.264 视频通过 NAS 播放。普通视频已连续播放至第 36 秒，并验证了暂停和进度跳转到第 30 秒后继续播放。测试不修改原始资料的标签、备注或阅读状态。

弹层打开时，底层工具栏和弹层不接收窗口拖动操作。播放器优先读取已保存的 NAS 视频；未保存时使用 X 原视频地址，并使用不携带页面来源的请求。加载失败时可重新加载。

安卓原生窗口的自动操作未能稳定获取焦点，原生配对、返回和视频播放没有完成验证。移动尺寸的前端检查不代替安卓实机验收。

Git 开发分支为 `main`，源码仓库为 GitHub 私有仓库 [X-like](https://github.com/1606835963aa/X-like)。签名文件、账号资料、构建产物和临时目录均在 Git 忽略范围内。
