## 功能检查

40 项自动测试与 7 项 Electron 采集场景检查通过，覆盖：

- 重复推文合并、收藏与点赞分别保存、再次同步保留整理信息。
- 中断同步保留已有资料，完整同步只更新对应账号与来源。
- 中文搜索、组合关键词、来源、媒体、日期与标签筛选。
- 归档恢复、JSON 备份恢复及双来源保留。
- X 长正文和引用解析，忽略广告。
- X `like.js`、JSON 与包含换行和逗号的 CSV 导入。
- 中文 CSV 重新导入及表格公式开头文字的保留。
- 两个设备访问同一服务，撤销设备后凭证失效，未授权请求拒绝访问。
- 服务重新启动后保留资料，并识别中断任务。
- 未保存媒体的普通请求和分段请求返回未保存状态，不触发 NAS 联网或新增媒体文件；图片和默认媒体保存任务被拒绝。
- 电脑手动获取指定视频并上传资料库，重复保存不重复获取，已保存视频支持分段读取。
- 作者按用户名聚合，同名不同账号分开，双来源资料去重；精确作者与标签、视频、来源可组合筛选。
- 作者名、用户名与标签的前缀联想优先，兼容大小写和全角形式，每次最多 8 条建议。
- 新增资料同步不请求、上传头像、预览图或视频。
- 新装与旧设置迁入后自动同步关闭；用户主动开启后的选择可保留。
- 增量读取只写入对应账号、来源的新内容，遇到整页已收录内容或重复翻页位置停止。
- HTTP 401、403、429 与响应正文中的限流、失效登录、账号锁定和验证提示停止整个同步；不重试、不继续另一种来源，已收录资料保留。
- 限流暂停时间在采集器重新创建后仍生效；支持等待秒数、日期和限流重置时间，不截短较长的等待要求。
- 等待下一页时可手动停止，历史读取请求在访问 X 前被拒绝。
- 中文、日文、英文与全角话题标签提取，大小写去重，忽略链接片段和纯数字标签。
- `#标签` 精确搜索、多标签与关键词组合筛选；手动标签和帖子标签按帖子去重计数。
- 旧资料库补齐话题标签后，正文、备注、手动标签、分类、来源与收录时间保持一致；再次打开可继续使用。
- 话题标签随正文更新、归档和恢复；JSON 与 CSV 导入、导出均保留两类标签。

NAS 已补齐已有资料的标签。更新前后的全部 1,706 条资料、账号和来源记录逐项核对一致，仅增加话题标签字段。资料备份位于本机项目 `private/backups/hashtags`。当前资料、媒体清单与程序备份位于 `private/backups/media-directory`，全部 1,706 条资料及账号、来源记录与备份逐项核对一致，5,566 个媒体与索引文件保持原样。

采集场景检查使用模拟 X 响应与独立本机测试资料库。正式 Mac 应用已确认自动同步开关为关闭状态，同步弹窗仅提供新增收藏与点赞，启动和界面核验未触发 X 采集。

TypeScript 类型检查与生产构建通过。

## 界面检查

共用前端在桌面和 375 像素手机宽度下检查了搜索、组合筛选、详情、标签、文件夹、备注、卡片与列表切换、浅色与深色、弹窗焦点和键盘操作。手机筛选面板没有横向溢出，日期控件可并排显示。9 组定义的文字颜色与背景对比检查通过。

手机布局使用底部导航和抽屉面板，桌面布局使用侧栏。界面截图位于 `release/screenshots`，使用独立资料副本展示。

作者与标签界面在 1280 像素桌面与 375 像素手机视口下检查，覆盖目录检索与翻页、卡片和详情标签跳转、关键词与标签组合、作者和标签联想选择，以及浅色和深色布局。新目录入口与手机作者表格截图为 `authors-desktop.jpg` 与 `authors-mobile.jpg`。标签截图为 `hashtags-desktop.jpg` 与 `hashtags-mobile.jpg`，使用独立测试资料。

正式 Mac 应用已启动并连接 NAS，作者目录显示 901 位作者，按用户名检索通过；NAS 的作者与视频组合筛选结果与目录计数一致。作者和标签目录支持检索、翻页与选择，日常筛选输入后显示最多 8 条联想建议，空输入不展开全部选项。

Electron 原生窗口使用独立测试资料与本机生成的视频检查：模拟 X 视频地址不可用时，播放器显示失败提示，资料库未新增文件；手动保存后仅写入该视频，已保存版本播放至第 3 秒。正式 NAS 对未保存视频的请求返回 HTTP 404，已保存视频的分段请求返回 HTTP 206。

弹层打开时，底层工具栏和弹层不接收窗口拖动操作。播放器优先读取已保存的 NAS 视频；未保存时使用 X 原视频地址，并使用不携带页面来源的请求。加载失败时可重新加载，不尝试由 NAS 下载；图片和头像直接由当前设备读取 X。只有电脑端的手动保存操作会向资料库写入视频。

安卓原生窗口的自动操作未能稳定获取焦点，原生配对、返回和视频播放没有完成验证。移动尺寸的前端检查不代替安卓实机验收。

Git 开发分支为 `main`，源码仓库为 GitHub 私有仓库 [X-like](https://github.com/1606835963aa/X-like)。签名文件、账号资料、构建产物和临时目录均在 Git 忽略范围内。
