# 验证与平台状态

版本：0.1.1。检查日期：2026 年 10 月 27 日。

## 自动检查

69 项单元与 API 测试覆盖资料去重、搜索、随机分页、导入导出、作者与标签、媒体策略、连接切换、升级备份、失败回滚和恢复。10 项 Electron 采集场景使用模拟 X 响应和独立本机资料，覆盖限流、登录失效、停止、连接失败、系统代理通道及手动视频保存。

TypeScript 检查与生产构建通过。独立源码包已完成从零安装依赖、单元与接口测试、生产构建；未复用原项目的 node_modules 或个人配置。跨系统 GitHub Actions 已配置，在线结果待实际运行确认。

## 启动、升级与恢复

实际 Mac 窗口使用独立测试资料，验证损坏数据库的启动错误、选择 SQLite 备份、恢复确认与自动重新打开，正常退出及恢复菜单重启通过。恢复后 7 条演示资料、标签及备注可见，原损坏文件另行保留，媒体文件不变。测试资料目录含中文与空格。

自动测试验证：备份包含已提交 WAL 内容；备份失败时不升级；迁移中途失败时回滚字段与内容；旧软件拒绝更高结构版本且不改写文件；恢复保留原数据库及 WAL；无效备份不会覆盖当前资料；旧备份缺少本机凭证时自动重新连接；本机恢复后打开本机资料并保留远程连接；关闭可重复调用；端口冲突后数据库连接会释放。

启动日志隐藏地址、个人路径与凭证。服务保留既有资料目录权限，Compose 运行身份通过部署配置生成，不固定为个人 NAS 的编号。

## X 登录

Mac 实际打开 X 官方登录页，点击 Google 会显示返回 X 登录的提示，返回入口可用。Apple 官方登录页可通过受控弹窗打开，完整账号登录和授权回跳尚需对应账号验收。

X 用户名或邮箱密码及账号验证在官方页面完成。模拟采集场景通过；真实账号同步与不同网络环境按设备继续验收。软件不读取其他浏览器的 Cookie。

## 默认保存与媒体

电脑版默认使用本机资料库，无需 NAS。单元与接口检查覆盖独立本机保存、远程凭证加密、本机与远程切换、选择的重启恢复及远程离线时回到本机。

浏览和同步不自动保存图片、头像或视频，未保存媒体不触发服务端访问 X。只有电脑主动保存选定视频时才写入当前资料库，已保存视频支持分段读取。JSON 用于迁移正文与整理信息，完整目录备份保留媒体与设备配置。

## 发行内容

Mac ZIP 的中文文件名、执行权限、14 个符号链接与压缩完整性通过检查。桌面包含项目 AGPLv3、依赖许可及 Chromium 许可。应用、界面与服务的版本取自 package.json，锁文件版本一致。

公开源码包包含必要的网页入口、构建配置、源代码和许可；不包含 Git 历史、个人配置、数据库、签名、node_modules 或安装包。当前源码公开检查通过，现有私有仓库历史仍含个人部署地址，历史检查会指出对应提交和文件。

现有 NAS 运行资料未用于故障测试，线上服务未重新部署。当前版本的 Docker 实际部署和 Windows 真机结果分别由对应环境确认。手机包不随当前桌面版本更新。

安装包、源码包与本机核验报告位于被 Git 忽略的 release；临时测试资料在检查后清理。
