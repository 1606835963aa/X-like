## 默认本机保存

正式 Mac 程序使用独立用户目录检查：未配置远程资料库时，默认读取本机收藏、标签与备注。设置显示资料保存在本机，连接远程资料库需要主动填写地址；本机模式不显示供其他设备连接的连接码。

本机和远程资料库共用搜索、整理、导入导出与手动视频保存能力。普通电脑上的独立服务已验证两个设备凭证之间的导入和查询。Android 当前为资料库客户端。

## 界面与品牌

桌面和 375 像素手机宽度下检查了检索、目录选择、长名称、浅深色、空状态和键盘操作。作者及标签目录宽屏三列、手机双列，完整匹配项连续展示，切换目录回到顶部，无横向溢出。

README 以中文为主，提供英文版和语言切换。两版图片、文档链接和页内目录检查通过。`docs/assets` 使用独立演示资料，包含桌面、手机、作者、标签、深色界面和双语封面。

图标由 `public/icon.svg` 统一生成。Mac ICNS 与源文件一致，Windows EXE 包含 6 个尺寸的新图标，Android 启动图标像素与源资源一致。iOS App Icon 为不含透明通道的 RGB PNG。

## 资料与媒体

实际部署中的正文、整理信息、账号与来源关系逐项核对保留，现有媒体与索引文件未新增或删除。界面测试使用独立资料。

浏览和同步不自动保存图片、头像或视频，未保存媒体的请求不会触发服务端访问 X。只有电脑端主动保存选定视频时，才向当前资料库写入视频；已保存视频支持分段读取。
